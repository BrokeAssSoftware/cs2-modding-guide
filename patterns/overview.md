# Patterns Overview

Reusable snippets and patterns distilled from community mods and vanilla templates. Use these documents when you need a quick reference for common Vice & Order module constructs.

- [Mod Bootstrap](mod-bootstrap.md) - load sequence, system registration, and Harmony patching.
- [Settings Patterns](settings.md) - Options UI attributes, reset actions, and persistence helpers.
- [Localisation Helper](localization.md) - dictionary sources tied to settings metadata.
- [System Registration](system-registration.md) - multi-phase scheduling and dependency ordering examples.

Keep full implementations inside module repositories; these snippets provide jumping-off points for new features.
