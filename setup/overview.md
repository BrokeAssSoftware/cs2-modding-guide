# Setup Overview

Use this section to get a workstation ready for Vice & Order development. The documents below cover everything from launch shortcuts to build and publish routines.

- [Launch Profiles](launch-profiles.md) - configure Steam, Xbox / PC Game Pass, and desktop shortcuts with developer flags.
- [Toolchain Installation](toolchain-installation.md) - install Unity, the modding project template, .NET, and Node via the in-game Modding panel.
- [Bootstrap a Code Mod](code-mod-bootstrap.md) - generate the base C# project and move it into the repository.
- [Bootstrap a UI Project](ui-project-bootstrap.md) - scaffold the Gameface React bundle and align IDs with the code mod.
- [Build and Publish Workflow](build-and-publish.md) - wire MSBuild, run daily build loops, and publish updates through the toolchain.
- [Environment Health Checks](environment-health-checks.md) - verify folders, certificates, and saves so development stays stable.

Return here whenever you onboard a new contributor or need to revisit a specific setup task.
