# Incident Response

- Collect affected save files, logs, and the list of active mods when players report issues.
- Reproduce using the closest regression save and document steps in the issue tracker.
- For regressions, create a hotfix branch, add automated coverage when possible, and rerun the release checklist before publishing.
- Share a short post-mortem in `docs/ops/reports/` when incidents reveal new process or automation gaps.
