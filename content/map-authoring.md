# Map and Scenario Authoring

1. **Terrain setup**
   - Lock elevation ranges early; changing them later disrupts water tables and spline meshes.
   - Sculpt river beds before importing road or rail splines.
2. **Resource painting**
   - Paint resources with broad, feathered brushes to avoid sharp simulation transitions.
3. **Climate and weather**
   - Adjust climate curves (temperature, precipitation, aurora) to fit the scenario and test with accelerated time.
4. **Checklist before export**
   - Set start tile, inbound/outbound connections, water availability, and localised display names.
   - Run the simulation preview for at least five in-game days to ensure services function.
